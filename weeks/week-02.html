Home » Schedule » Week 2: Shell Fundamentals and Dotfiles
Week 2 of 15

Tuesday & Thursday, September 1 & 3

Part of Mini-Project 1 — Development Environment Configuration (Weeks 1–2).

Learning Goals

Shell fundamentals (zsh, .zprofile/.zshrc, XDG base directories), modern CLI toolkits (ripgrep, fzf, bat, eza, tmux), VS Code setup, dotfiles-as-code. First quiz.

This week we will use our newly configured laptops to explore:

  • terminal command line interface (CLI)
  • Claude Code CLI integrated development environment (IDE)
  • Microsoft Visual Studio Code (VSCode)
  • GitHub.com and local CLI apps “git” and “gh”

We will also introduce Mini-Project #1: Redesigning a Website by applying some of the concepts we learn in class.
